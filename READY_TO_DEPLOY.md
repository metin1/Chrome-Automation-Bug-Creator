## 🚀 Get Started

### Step 1: Build
```bash
npm run build
```

### Step 2: Load
```
chrome://extensions/
→ Developer mode ON
→ Load unpacked
→ Select dist/ folder
```

### Step 3: Use
```
1. Go to any website
2. Click extension icon
3. Fill form or click "Generate"
4. Create GitHub issue!
```
