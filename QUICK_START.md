# 🚀 Quick Start - GitHub Issue Creator
## Install in 3 Steps
### 1️⃣ Open Chrome Extensions
```
chrome://extensions/
```
Enable "Developer mode" (top-right toggle)
### 2️⃣ Load Extension
Click "Load unpacked" → Select the `dist` folder
### 3️⃣ Configure GitHub Token
1. Click extension icon → Settings tab
2. Get token: https://github.com/settings/tokens/new (scope: `repo`)
3. Paste token → Validate → Save
## Usage
**Keyboard Shortcut**: `Cmd+Shift+I` (Mac) or `Ctrl+Shift+I` (Windows)
### Create an Issue:
1. Open any webpage
2. Press the shortcut to open extension
3. Select **Console** tab → Select errors
4. Select **Network** tab → Select failed requests
5. Go to **Main** tab
6. Select repository
7. Click "Generate from Captured Data"
8. Click "Create GitHub Issue"
## That's it! 🎉
