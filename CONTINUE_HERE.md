## 🎯 The Next 15 Minutes

**Step-by-step to get it running:**

### Minute 1-2: Load Extension
```
1. Go to: chrome://extensions/
2. Toggle "Developer mode" ON
3. Click "Load unpacked"
4. Select: /dist/ folder
5. Click "Select"
```

### Minute 3-5: Generate Token
```
1. Go to: github.com/settings/tokens/new
2. Name: "GitHub Issue Creator"
3. Scope: "repo" ✓
4. Click "Generate token"
5. Copy the token
```

### Minute 6-10: Configure Extension
```
1. Click extension icon
2. Go to "⚙️ Settings" tab
3. Paste your token
4. Click "Validate Token"
5. See: ✅ "Token is valid"
```

### Minute 11-15: Test It
```
1. Go to any website
2. Click extension icon
3. Check "Console" tab - see logs?
4. Check "Network" tab - see requests?
5. Go to "Main" tab
6. Fill form and click "Create GitHub Issue"
```
