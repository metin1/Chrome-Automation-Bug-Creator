# Icon Placeholder

Place your extension icons here:
- icon16.png (16x16)
- icon48.png (48x48)
- icon128.png (128x128)

You can generate icons using:
- Online tools like https://www.favicon-generator.org/
- Design tools like Figma, Photoshop, or Canva
- Simple SVG to PNG conversion

For now, create simple placeholder icons or use a generic GitHub icon.

To generate icons quickly:
1. Create an SVG with a simple design (bug icon, GitHub logo, etc.)
2. Convert to PNG at the required sizes
3. Place them in this directory
