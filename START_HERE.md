## 🚀 Get Started in 2 Steps

### Step 1: Build
```bash
cd /Users/metin/Documents/github/Chrome-Automation-Bug-Creator
npm run build
```

### Step 2: Load in Chrome
1. Go to `chrome://extensions/`
2. Turn on "Developer mode" (top right toggle)
3. Click "Load unpacked"
4. Select the `dist/` folder
5. Done! You'll see the extension in your toolbar

---

## 📝 Use It - 3 Ways

### Way 1: Quick (30 seconds)
1. Open extension
2. Click "📋 Generate from Captured Data"
3. Click "🚀 Create GitHub Issue"
✅ Issue created with all data!

### Way 2: With Custom Logs (1 minute)
1. Paste logs in "Additional Logs (Optional)" field
2. Click "📋 Generate from Captured Data"
3. Add title, select repo, create issue
✅ Professional issue with custom logs!

### Way 3: Full Control (2 minutes)
1. Edit title
2. Paste custom logs
3. Generate from captured data
4. Edit description if needed
5. Select repository & labels
6. Create issue
✅ Perfect, personalized issue!
